# RealSense SAM2 Tracker Documentation



⚠️ **Document Generated By AI** ⚠️

## Overview

The `RealSenseSegmentationTracker` is a real-time object segmentation and tracking system that combines Intel RealSense cameras with Meta's SAM2 (Segment Anything Model 2) for interactive object tracking. Users can click on objects in the live camera feed to define what they want to track, and the system will maintain segmentation masks across video frames in real-time.

## Features

- **Real-time Video Streaming**: Live video feed from Intel RealSense cameras
- **Interactive Point Collection**: Click-based object selection for tracking initialization
- **Multi-object Tracking**: Track multiple objects simultaneously with different colored masks
- **Real-time Segmentation**: SAM2-powered segmentation with live mask visualization
- **Keyboard Controls**: Simple keyboard interface for operation control

## Prerequisites

- Intel RealSense camera (D435, D455, or compatible model)
- NVIDIA GPU with CUDA support (recommended for optimal performance)
- USB 3.0 port for camera connection

## Usage

### Basic Usage

Run the tracker with default settings:

```bash
python scripts/segmenter/realsense_tracker.py
```

### Advanced Usage

Customize the tracker with specific parameters:

```python
from scripts.segmenter.realsense_tracker import RealSenseSegmentationTracker

# Initialize with custom settings
tracker = RealSenseSegmentationTracker(
    sam2_checkpoint="checkpoints/sam2.1/sam2.1_hiera_large.pt",
    model_cfg="configs/sam2.1/sam2.1_hiera_l.yaml",
    rs_serial=242422304947  # Your camera's serial number
)

# Start tracking
tracker.run()
```

## Controls

### Mouse Controls

- **Left Click**: Add positive point (object to track)
- **Right Click**: Add negative point (background/not to track)

### Keyboard Controls

- **'s'**: Start tracking with collected points
- **'r'**: Reset all collected points
- **'q'**: Quit the application

## Workflow

1. **Launch the Application**: Run the script to start the camera feed
2. **Collect Points**: Click on objects you want to track
   - Use left clicks for objects you want to track
   - Use right clicks for areas you want to exclude
3. **Start Tracking**: Press 's' to begin real-time segmentation
4. **Monitor Results**: Watch the colored masks track your objects
5. **Reset if Needed**: Press 'r' to clear points and start over

## Visual Interface

### Point Collection Mode
- Green circles: Positive points (objects to track)
- Red circles: Negative points (background)
- Numbered labels: Point sequence

### Tracking Mode
- Colored masks: Each tracked object has a unique color
- Frame counter: Shows current tracking frame
- Object count: Number of actively tracked objects

## Troubleshooting

### Common Issues

#### 1. Camera Not Detected
```
Error: RealSense camera not found
```
**Solution**: 
- Check USB connection
- Verify camera is powered on
- Update RealSense SDK
- Check camera serial number in code

#### 2. CUDA Out of Memory
```
RuntimeError: CUDA out of memory
```
**Solution**:
- Use a smaller SAM2 model (e.g., `sam2.1_hiera_small.pt`)
- Reduce camera resolution in the code
- Close other GPU-intensive applications

#### 3. Config File Not Found
```
Error: Cannot find primary config
```
**Solution**:
- Verify config file exists at specified path
- Check file permissions
- Ensure correct relative path from project root

#### 4. Poor Tracking Performance
**Solutions**:
- Ensure good lighting conditions
- Use high-contrast objects
- Add more positive points for better initialization
- Use negative points to exclude confusing background

### Performance Optimization

1. **GPU Memory**: Use smaller models for limited GPU memory
2. **Camera Resolution**: Lower resolution for better performance
3. **Point Quality**: More accurate initial points improve tracking
4. **Lighting**: Good lighting improves segmentation quality

## Technical Details

### Architecture

- **Camera Interface**: Intel RealSense SDK for video capture
- **Segmentation**: Meta SAM2 for object segmentation
